# Quality

Use this directory for quality standards, test strategy, Definition of Done, and verification guidance.

## Files

- `dod-checklist.md` - Definition of Done checklist
- `test-strategy.md` - project testing approach
- `manual-tests/` - manual test cases and verification steps

## Quality Rules

- Verification should match the risk and scope of the change.
- Automated checks are preferred for repeated behavior.
- Manual checks should include exact steps and expected results.
- Known gaps must be documented before handoff.
