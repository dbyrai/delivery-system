# Manual Tests

Use this directory for repeatable manual verification steps.

Manual tests should be specific enough that another person can run them and reach the same conclusion.

## Naming

```text
MT-001-login-flow.md
MT-002-navigation.md
```

## Manual Test Template

```markdown
# Manual Test: [Title]

**ID**: MT-001
**Related Requirement/Task**: [REQ-ID / TASK-ID]
**Owner**: [Role/name]
**Last Updated**: YYYY-MM-DD

## Preconditions

- [Required setup]

## Steps

1. [Action]
2. [Action]

## Expected Result

- [Expected outcome]

## Actual Result

- [Fill in during execution]

## Status

Pass | Fail | Blocked

## Notes

- [Evidence, screenshots, logs, or follow-up]
```
