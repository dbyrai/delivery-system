# Baseline Acceptance Criteria

These criteria apply to project deliverables unless a spec defines more specific acceptance criteria.

## General Acceptance

- AC-BASE-001: The delivered work matches the approved requirement or spec.
- AC-BASE-002: Relevant documentation is updated.
- AC-BASE-003: Verification evidence is recorded.
- AC-BASE-004: Known risks, limitations, and open questions are documented.
- AC-BASE-005: No real secrets or sensitive data are introduced.

## Implementation Acceptance

- AC-BASE-006: Relevant tests, linting, type checks, builds, or manual checks have been run where applicable.
- AC-BASE-007: Error handling is covered for expected failure cases.
- AC-BASE-008: The work is small enough to review and hand off.

## Review Acceptance

- AC-BASE-009: Review findings include file references or concrete evidence.
- AC-BASE-010: Blocking issues are separated from recommendations.
