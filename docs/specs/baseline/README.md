# Baseline Requirements

Baseline requirements apply across the whole project unless a specific spec explicitly overrides them.

Use this directory for global standards that should not be repeated in every spec.

## Files

- `functional-requirements.md` - global functional expectations
- `non-functional-requirements.md` - performance, reliability, accessibility, maintainability, and compatibility expectations
- `security-policy.md` - security, privacy, data handling, and policy requirements
- `acceptance-criteria.md` - global acceptance and sign-off criteria

## Rule

Specs may add stricter requirements. If a spec needs to differ from a baseline requirement, document the reason in the spec.
