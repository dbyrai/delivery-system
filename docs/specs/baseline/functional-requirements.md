# Baseline Functional Requirements

These requirements apply across the project unless a spec states otherwise.

## Global Functional Requirements

- FR-BASE-001: User-facing behavior must be derived from documented requirements.
- FR-BASE-002: Important user flows must define success, empty, error, and recovery states where applicable.
- FR-BASE-003: Data inputs and outputs must be documented when they cross system or module boundaries.
- FR-BASE-004: User-visible text must preserve approved business wording unless explicitly changed.
