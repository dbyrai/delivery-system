# Baseline Non-Functional Requirements

These requirements apply across the project unless a spec states otherwise.

## Performance

- NFR-BASE-001: Performance expectations must be defined for user-critical flows before implementation is marked complete.

## Reliability

- NFR-BASE-002: The system should handle expected error conditions with clear fallback behavior.

## Accessibility

- NFR-BASE-003: User-facing interfaces should support keyboard navigation and readable text contrast for the implemented scope.

## Maintainability

- NFR-BASE-004: Implementation should follow existing project structure, naming, and tooling.
- NFR-BASE-005: Complex decisions should be documented in `docs/project/decisions.md`.

## Compatibility

- NFR-BASE-006: Supported environments, browsers, runtimes, or platforms must be documented when relevant.
