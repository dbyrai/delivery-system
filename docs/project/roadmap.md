## Delivery Phases

### Phase 1: Discovery And Baseline

- Define project goals and constraints.
- Capture baseline requirements.
- Identify risks and open questions.

### Phase 2: Specification

- Create detailed specs.
- Review acceptance criteria.
- Confirm dependencies and ownership.

### Phase 3: Implementation

- Break specs into tasks.
- Implement in small, verifiable increments.
- Track artifacts and decisions.

### Phase 4: Verification And Delivery

- Execute automated and manual checks.
- Complete Definition of Done.
- Prepare delivery notes and handoff.
