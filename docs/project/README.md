# Project

Use this directory for project-level context that applies across specs and tasks.

## Files

- `overview.md` - concise project purpose, goals, scope, stakeholders, and success criteria
- `roadmap.md` - phases, milestones, sequencing, and delivery plan
- `decisions.md` - accepted project and architecture decisions

## Guidance

- Keep project-level documents stable and concise.
- Put detailed requirements in `docs/specs/`.
- Put implementation breakdowns in `docs/tasks/`.
- Record important decisions once, then link to them from specs or tasks.
