# Delivery System routing for Kiro

Read and follow `.github/copilot-instructions.md` before working in this
repository. It is the canonical workflow. If it cannot be read, report the
missing context before dependent work.

Select roles through `.github/agents/README.md`; loading a role does not create
or launch a custom agent. Load shared skills only when the request matches them.

For Kiro-native specs, read the durable Kiro integration record and the mapped
authoritative requirements, decisions, specifications, and task files. Generated
artifacts are working views, not approval. Preserve stable IDs, blockers,
dependencies, and acceptance evidence. Stop on mapping conflicts or unresolved
blocking questions.
