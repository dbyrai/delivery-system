# Delivery System routing for Kiro

Read and follow `.github/copilot-instructions.md` before working in this repository.
It is the canonical shared workflow; this steering file adds no alternative
source-of-truth order. If it cannot be read, report the missing context before
dependent work.

Select roles through `.github/agents/README.md` and read only the selected role's
complete file. Role selection does not launch a custom agent or subagent.

For work on a Kiro-native spec, read its requirements, design, and tasks plus
the linked authoritative project sources and integration record. Kiro artifacts
are working views of those sources. Do not infer approval from a generated spec
or completed checkbox. Preserve established IDs and record acceptance evidence
in the authoritative delivery task before marking its Kiro counterpart complete.

Use project-specific routing in the canonical shared instructions to locate the
integration record. Report missing mappings or conflicts before dependent work.
