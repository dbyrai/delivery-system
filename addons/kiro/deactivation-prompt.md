# Kiro Deactivation Prompt

```text
Deactivate the optional Kiro workflow add-on in this project.

Read the applicable instructions and durable Kiro record. Inspect installed
steering, routing, native specs, custom-agent resources, and the working tree.
Identify pending native changes or acceptance evidence that must be reconciled
into authoritative project documents. Obtain decisions for unresolved retention
or deletion; preserve specs, history, IDs, and evidence by default.

Remove only add-on-owned steering and its conditional routing pointer. Preserve
unrelated Kiro configuration, shared instructions, roles, skills, AGENTS.md, MCP
access, and external integrations. Mark the durable record inactive and record
retained artifacts and verification. Deleting addons/kiro is a separate action.

Verify paths and links and, when available, use a fresh Kiro conversation to
confirm the add-on steering is no longer loaded. Report unavailable live checks
as pending. Do not commit, push, merge, publish, or change external access without
separate authorization.
```
